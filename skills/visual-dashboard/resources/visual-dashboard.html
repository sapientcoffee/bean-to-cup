🧩 Chosen ADK Orchestration Pattern

Coordinator-Specialist Pattern

This pattern coordinates specialized agent experts to analyze user inputs and route tasks dynamically. Perfect for executing custom bean grinding vs milk frothing operations.

  • Coordinator: Routes and delegates to specialists based on prompt.
  • Grind Specialist: Analyzes extraction ratios and adjusts particle sizes.
  • Observability Specialist: Stores telemetry events to Cloud Logging.
